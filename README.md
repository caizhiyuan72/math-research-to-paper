# Math Research to Paper | 数学科研与论文写作

A reusable ChatGPT / Codex skill for mathematical research: literature search, conjecture discovery, exact computation, rigorous proof, independent verification, LaTeX manuscripts, simulated peer review and revision.

一个用于数学科研的可复用 Skill：从文献检索、选题、猜想、精确计算和严格证明，到独立核验、LaTeX 论文、多轮模拟审稿与修订。

## 使用 / Usage

- 下载本仓库源码，将 `math-research-to-paper/` 作为一个完整 Skill 目录使用；支持 Skill 的环境可按其导入方式安装。
- 在对话中调用 `$math-research-to-paper`，并提供研究领域、已有论文或待解决问题。
- 查看 `math-research-to-paper/SKILL.md`、`references/`、`assets/` 和 `scripts/` 了解具体工作流程及模板。

Example: `使用 $math-research-to-paper，阅读最近一周 arXiv 上的组合数学论文，筛选有价值的开放问题，尝试严格证明并提供可复现的研究材料。`

## Research integrity | 科研规范

Distinguish conjectures, finite experiments, proofs and verified literature. Never treat finite enumeration as a universal proof, invent citations, or claim independent human peer review. The claim-ledger checker validates bookkeeping, not mathematical truth.

区分猜想、有限实验、证明和已核实文献；计算结果不是一般性证明，AI 模拟审稿也不等同于真实同行评审。
